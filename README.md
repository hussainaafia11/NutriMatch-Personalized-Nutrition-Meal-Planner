# 🥗 NutriMatch — Personalized Nutrition & Meal Planner

NutriMatch is a responsive web application that helps users discover foods based on their nutritional goals and create personalized meal plans according to their dietary preferences, budget, cooking time, and food restrictions.

The project is designed as a simple **food decision and meal-planning assistant**, making nutrition planning more practical and accessible.

---

## ✨ Features

### 🎯 Personalized Nutrition Goals

Users can select the nutrients they want to prioritize:

- 🩸 Iron
- 💪 Protein
- ⚡ Vitamin B12
- ☀️ Vitamin D
- 🦴 Calcium
- 🌾 Fiber
- 🍊 Vitamin C
- 🌿 Folate
- 🥕 Vitamin A

### 🥗 Dietary Preferences

Supports multiple dietary preferences:

- Vegetarian
- Vegan
- Eggetarian
- Non-vegetarian

### 💰 Budget-Based Planning

Users can select their approximate daily food budget:

- Under ₹150
- ₹150–₹300
- ₹300+

### ⏱️ Cooking-Time Preferences

Meal recommendations can be adjusted according to available cooking time:

- 15 minutes or less
- Around 30 minutes
- Flexible cooking time

### 🚫 Food Avoidance

Users can specify foods they want to avoid, and the recommendation system filters them from the results.

### 🍎 Food Recommendations

NutriMatch generates food recommendations based on:

- Selected nutritional goals
- Dietary preference
- Budget
- Cooking time
- Foods to avoid

Each recommendation includes a **match score** and highlights the nutrients associated with the selected goals.

### 🍱 Personalized Meal Plan

The application generates a simple daily meal plan containing:

- Breakfast
- Lunch
- Snack
- Dinner

Users can also shuffle the meals to explore alternatives.

### 📊 Nutrient Snapshot

The dashboard provides visual indicators showing how well the generated meal plan covers selected nutrients.

### 🛒 Automatic Grocery List

The selected meal plan generates a categorized grocery list.

Users can also copy the grocery list with one click.

### 📱 Responsive Interface

The application is built with Bootstrap and is designed to work across:

- Desktop
- Tablet
- Mobile
